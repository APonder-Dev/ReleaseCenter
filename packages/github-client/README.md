# @releasecenter/github-client

GitHub App authentication and Octokit-based GitHub API integration:
installation token issuance and refresh, repository discovery, pull
request/tag/release retrieval, tag and release creation, webhook signature
verification, and GitHub API error/rate-limit mapping.

Implemented in Phase 4 (GitHub App Integration). See
`docs/github-app-setup.md` for the requested permission set once written.
